### Bimailar

Проект библиотеки для работы с почтовыми архивами в бинарном формате. Она решает следующие проблемы:

- более компактный бинарный формат хранения по сравнению с maildir и mailbox
- максимальная дедупликация повторяющихся данных вроде названий заголовков
- поддержка сжатия на уровне отдельных сообщений
- ориентировка на сценарий преимущественно чтения и добавления, без перезаписи архива даже в случае удаления сообщений
- поддержка меток сообщений на уровне архива
- структура файла архива сделана из расчета на работу несколькими подходами:
  - Сценарий для поиска по большим архивам в режиме пакетной обработки: выборка по одному сообщению последовательным чтением
  - Сценарий для интерактивной интерактивной работы, например из почтового клиента: загрузка архива в память, быстрый доступ к конкретному сообщению
